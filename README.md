# Paulo Vespero

Estudante de Ciência da Computação no **Instituto Mauá de Tecnologia** (4º ano), com foco em **machine learning, deep learning e agentes de IA**. Gosto de entender os modelos por dentro: treino localmente na minha própria GPU, escrevo o loop de treino à mão e meço tudo contra uma referência simples antes de confiar no resultado.

## Projetos em destaque

| Projeto | O que é | Stack |
| --- | --- | --- |
| [**pytorch-do-zero**](https://github.com/pauloVesperoo/pytorch-do-zero) | Trilha prática de deep learning em PyTorch, do primeiro tensor a um modelo servido por API. CNN no CIFAR-10, classificação e regressão com motor de treino próprio (early stopping, scheduler), tudo treinado localmente numa GPU AMD com ROCm | PyTorch, ROCm, scikit-learn, WSL |
| [**agent_hub**](https://github.com/pauloVesperoo/agent_hub) | Central desktop para criar, agendar e acompanhar agentes de IA que pesquisam na web e entregam relatórios | Electron, React, TypeScript, Claude Code |
| [**ia-labs**](https://github.com/pauloVesperoo/ia-labs) | Trabalhos de machine learning e deep learning da faculdade: previsão de churn com modelos clássicos e redes neurais em Keras | scikit-learn, TensorFlow/Keras |
| [**CityRain**](https://github.com/Rodrigomt21/CityRain) | TCC: monitoramento de chuva urbana com visão computacional embarcada em Jetson Nano e mapa em tempo real. Apresentado no CONIC e na Eureka 2026 | Python, CNN, Jetson Nano, React |
